# Apuntes: Sistemas Operativos Actuales

Descripción general de los sistemas operativos actuales en concreto Linux, Ubuntu, kali-linux, Windows y macOS


## 1. Linux

- Descripción:
    - Es un sistema operativo de código abierto basado en Unix, diseñado para ser altamente personalizable, seguro y eficiente.
    - Unix es la base fundamental para muchos sistemas operativos modernos, incluyendo Linux y macOS, se caracteriza por su estabilidad y uso en servidores y entornos empresariales.
    - Fedora es una distribución de Linux patrocinada por Red Hat, conocida por integrar tecnologías innovadoras antes de ser implementadas en RHEL.
    - RHEL (Red Hat Enterprise Linux) es la versión empresarial de Linux, enfocada en estabilidad y soporte a largo plazo, utilizada en corporaciones y gobiernos.

- Características principales:
    - Núcleo (Kernel): Linux es el kernel que da origen a múltiples distribuciones.
    - Estabilidad y rendimiento: Ideal para servidores y estaciones de trabajo.
    - Alta compatibilidad: Se usa en sistemas embebidos, IoT, supercomputadoras y dispositivos personalizados.
    - Comunidad activa: Miles de desarrolladores y empresas contribuyen a su evolución.
    - Distribuciones populares:
    - Ubuntu: Fácil de usar, ideal para principiantes y servidores.
    - Debian: Base sólida y estable para muchas otras distribuciones.
    - Fedora: Innovadora y vanguardista, patrocinada por Red Hat.
    - Arch Linux: Altamente personalizable y optimizada para usuarios avanzados.

- Usos comunes:
    - Servidores web, bases de datos, y hosting.
    - Desarrollo de software y administración de sistemas.
    - Seguridad informática y análisis forense.
    - Computación en la nube (AWS, Google Cloud, Azure).

## 2. Ubuntu (Distribución de Linux)

- Descripción:
    - Esta basado en Debian, Ubuntu es una de las distribuciones más populares de Linux, conocida por su facilidad de uso y amplio soporte comunitario.
    - Desarrollada por Canonical, Ubuntu ofrece versiones tanto para usuarios domésticos como empresariales.

- Características principales:
    - Facilidad de instalación: Diseñada para ser accesible a principiantes.
    - Entorno gráfico: Usa GNOME por defecto, aunque soporta escritorios alternativos como KDE (Kubuntu), Xfce (Xubuntu) y MATE (Ubuntu MATE).
    - Versiones LTS (Long Term Support):
    - Ofrece 5 años de soporte en versiones estables.

- Seguridad y actualizaciones:
    - Se actualiza regularmente con parches de seguridad.
    - Compatible con herramientas como AppArmor y UFW (Uncomplicated Firewall).

- Aplicaciones preinstaladas:
    - LibreOffice: Alternativa gratuita a Microsoft Office.
    - Firefox: Navegador web predeterminado.
    - GIMP, VLC y Thunderbird: Herramientas multimedia y de correo.

- Usos comunes:
    - Servidores y Cloud Computing: Amplia adopción en plataformas como AWS, Google Cloud y Azure.
    - Desarrollo de software: Compatible con Python, Java, C++, Docker y Kubernetes.
    - Educación y estaciones de trabajo: Preferido en universidades y empresas tecnológicas.
    - Uso personal: Alternativa gratuita y libre a Windows y macOS.

## 3. Kali Linux (Distribución de Linux)

- Descripción:
    - Es una distribución basada en Debian, diseñada específicamente para pruebas de penetración y seguridad informática.
    - Esta desarrollada por Offensive Security, Kali Linux es utilizada por pentesters, analistas de seguridad y forenses digitales.

- Características principales:
    - Herramientas integradas:
        - Incluye más de 600 herramientas de hacking ético, análisis forense y auditoría de seguridad.
        - Destacan Nmap, Metasploit, Wireshark, Aircrack-ng y John the Ripper.
    - Interfaz gráfica optimizada:
        - Usa entornos ligeros como XFCE, permitiendo un rendimiento ágil en hardware limitado.
        - También soporta KDE y GNOME para configuraciones avanzadas.
    - Modo Live:
        - Se puede ejecutar directamente desde un USB sin necesidad de instalación.
        - Útil para auditorías rápidas sin afectar el sistema anfitrión.
    - Soporte para ARM y dispositivos móviles:
        - Disponible para Raspberry Pi, Android (NetHunter) y sistemas embebidos.
    - Seguridad avanzada:
        - Ejecuta a los usuarios en modo no-root por defecto para reducir riesgos.
        - Puede personalizarse con herramientas adicionales según las necesidades del usuario.

- Uso común:
    - Pentesting y auditorías de seguridad: Pruebas de vulnerabilidades en redes y sistemas.
    - Análisis forense digital: Investigación de incidentes de seguridad.
    - Entrenamiento y aprendizaje: Formación en ciberseguridad y hacking ético.

## 4. Windows

- Descripción:
    - Su Sistema operativo esta desarrollado por Microsoft, líder en el mercado de computadoras personales.
    - Última versión: Windows 11 (con actualizaciones periódicas y soporte extendido).

- Características principales:
    - Interfaz gráfica intuitiva: Basada en ventanas (GUI - Graphical User Interface) para facilitar la experiencia del usuario.
    - Compatibilidad de software: Soporte para una gran variedad de aplicaciones comerciales, herramientas de productividad y videojuegos.
    - Actualizaciones y seguridad:
    - Windows Update: Proporciona actualizaciones automáticas de seguridad y nuevas funciones.
    - Windows Defender: Antivirus integrado con protección en tiempo real.
    - BitLocker: Cifrado de disco completo en ediciones Pro y Enterprise.

- Ediciones disponibles:
    - Windows 11 Home: Orientado a usuarios domésticos.
    - Windows 11 Pro: Funciones avanzadas para profesionales y empresas.
    - Windows 11 Enterprise: Seguridad y administración a gran escala para corporaciones.

- Uso común:
    - Computadoras personales.
    - Empresas y entornos corporativos.
    - Estaciones de trabajo profesionales.
    - Gaming: Amplia compatibilidad con DirectX y optimización para hardware de juegos.
    - Integración con la nube:
    - OneDrive: Sincronización de archivos en la nube.
    - Microsoft 365: Suite de productividad con Word, Excel, y Outlook.
    - Azure AD: Autenticación y gestión de identidades empresariales.
    - Compatibilidad con hardware: Soporta una amplia gama de dispositivos, desde PCs de bajo costo hasta estaciones de alto rendimiento.

## 5. MacOs

- Descripción:
    - Su sistema operativo esta desarrollado por Apple Inc.
    - Última versión: macOS Sonoma (2023).
    - Diseñado para funcionar exclusivamente en hardware Apple (MacBook, iMac, Mac Mini, Mac Studio, Mac Pro).
    - Características principales:
    - Interfaz elegante y fluida: Diseño intuitivo basado en el concepto de escritorio con Dock y Mission Control.
    - Optimización con hardware Apple:
    - Integración con chips Apple Silicon (M1, M2, M3) para mayor eficiencia y rendimiento.
    - Menor consumo de energía y mayor duración de batería en MacBooks.

- Seguridad avanzada:
    - FileVault: Cifrado de disco completo.
    - Gatekeeper: Controla la instalación de aplicaciones solo desde fuentes verificadas.
    - XProtect: Protección contra malware integrada.
    - Ediciones y dispositivos compatibles:
    - macOS estándar para todos los dispositivos Mac.
    - Compatible con modelos recientes y algunos anteriores con actualizaciones.
    - Ecosistema Apple:
    - Handoff, Continuity y AirDrop: Conexión fluida con iPhone, iPad y Apple Watch.
    - iCloud: Sincronización automática de archivos, fotos y configuraciones.
    - Sidecar: Usa un iPad como pantalla secundaria para Mac.

- Uso común:
    - Profesionales del diseño, edición de video y desarrollo de software.
    - Empresas que usan dispositivos Apple.
    - Usuarios que buscan estabilidad y larga vida útil en sus equipos.
    - Compatibilidad con software:
    - Soporte nativo para aplicaciones macOS (Final Cut Pro, Logic Pro, Xcode).
    - Rosetta 2: Permite ejecutar aplicaciones diseñadas para procesadores Intel en chips Apple Silicon.
    - Virtualización: Se puede instalar Windows o Linux mediante Parallels, VMware o Boot Camp (solo en Macs Intel).

## 7. Gestión de Identidad y Acceso (IAM - Identity and Access Management) en Diferentes Sistemas Operativos

- Es crucial para garantizar la seguridad en sistemas operativos, cada plataforma tiene su propio enfoque para administrar autenticación, autorización y control de acceso.

- Linux/Unix
    - En entornos Linux y Unix, la IAM se maneja con una combinación de herramientas y protocolos:

    - LDAP (Lightweight Directory Access Protocol)

        - Protocolo estándar para la autenticación centralizada en redes empresariales.
        - Se usa para almacenar credenciales y permisos de usuarios.
        - Integración con OpenLDAP y Active Directory (AD).
        - PAM (Pluggable Authentication Modules)

    - Framework modular que permite autenticación flexible.
        - Soporta autenticación mediante contraseña, biometría, tarjetas inteligentes, etc.
        - Utilizado por SSH, sudo y otros servicios críticos.
        - Active Directory (AD)

    - Aunque es una tecnología de Microsoft, se puede integrar con Linux usando Samba o SSSD (System Security Services Daemon).
        - Permite a los servidores Linux autenticarse en dominios Windows.
        - Kerberos

    - Protocolo de autenticación de red que permite autenticación única (SSO).
        - Utilizado en muchas implementaciones empresariales de IAM.

- Windows
    - Windows tiene un enfoque unificado para IAM, centrado en Active Directory (AD):

    - Active Directory (AD)

        - Base de datos jerárquica para la autenticación y autorización en redes Windows.
        - Soporta políticas de acceso, administración de grupos y control centralizado de usuarios.
        - Utiliza LDAP, Kerberos y NTLM como protocolos de autenticación.
        - Azure Active Directory (Azure AD)

    - Variante en la nube de AD, utilizada para entornos híbridos y cloud-native.
        - Integración con Single Sign-On (SSO), Multi-Factor Authentication (MFA) y OAuth.
        - Windows Hello for Business

    - Autenticación basada en biometría o PIN, en lugar de contraseñas tradicionales.
        - BitLocker y Gestión de Dispositivos

    - Protección del acceso mediante cifrado de disco y administración remota con Intune y Group Policy (GPO).

- MacOS
    - Apple ofrece un enfoque integrado con su ecosistema, con un fuerte énfasis en la privacidad y la biometría:


    - iCloud y Apple ID

        - Base de autenticación para servicios de Apple, incluyendo FileVault, App Store y iCloud Keychain.
        - Soporte para autenticación de dos factores (2FA).
        - Active Directory y Open Directory

    - macOS puede unirse a un dominio de Windows AD para autenticación empresarial.
        - Open Directory es la alternativa de Apple a AD, usado en redes macOS.
        - Touch ID y Face ID

    - Integración con el sistema de autenticación biométrica para desbloqueo de dispositivos y acceso a aplicaciones.
        - FileVault y T2 Security Chip

    - Cifrado de disco completo para proteger datos.
        - El chip T2 impide accesos no autorizados y refuerza la seguridad de claves.
